Agency in a Box Documentation

01

Getting started

Choose Done-for-You when you want Hello World Studio to deliver the completed system. Choose Agency Edition when you want reusable access for several clients.

02

Local storage

The current Agency Edition saves its working data in the browser on the current device.

03

Backups

Export the client library regularly and store the backup safely.

04

AI mode

Use the built-in workflow by default. Browser-entered API keys should not be treated as a secure long-term production method.
